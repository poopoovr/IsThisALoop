# IsThisALoop
[IsThisALoop](https://github.com/poopoovr/IsThisALoop/) is a mod for **Gorilla Tag** that records your movements and creates physical clones of your gorilla that follow your exact past path.

# 💾 Installation

- Download the release from [here](https://github.com/poopoovr/IsThisALoop/releases/latest)
- Drag the file `IsThisALoop.dll` to your plugins folder
- Start Gorilla Tag if needed
